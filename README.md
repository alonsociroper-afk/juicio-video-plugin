# juicio-video

Plugin de Claude Code que somete una idea de video a un juicio:

- **abogado-defensor**: por qué el video es bueno
- **fiscal**: por qué el video es malo
- **perito-aburrimiento**: "ve" el video y marca dónde aburre
- **perito-gancho**: cuestiona el gancho, el título y la miniatura
- **perito-tema**: cuestiona el tema y el ángulo
- **juez**: dicta sentencia y entrega el video perfecto para subir

## Instalar
```
/plugin marketplace add <ruta-a-esta-carpeta-o-repo-github>
/plugin install juicio-video@alonso-plugins
```

## Usar
```
/juicio-video finanzas para jóvenes, TikTok, 18-25 años
```
O pega tu guion o tu idea después del comando.
